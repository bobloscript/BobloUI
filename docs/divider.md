# Divider

Visual separator with optional title.

Constructor: `AddDivider({...})`

Stateful: **no**

## Options
- `Id`: string?
- `Title`: string?
- `Description`: string?
- `Keywords`: table?
- `Badge`: string?
- `Disabled`: boolean|string?
- `Visible`: boolean?
- `VisibleWhen`: table|function?
- `EnabledWhen`: table|function?
- `IgnoreConfig`: boolean?
- `Order`: number?
- `Callback`: function?
- `Tooltip`: string|function?
- `ContextMenu`: table?
- `Adaptive`: boolean?
- `Icon`: string?
- `IconColor`: string|Color3?
- `Text`: string?
- `Margin`: number?
- `MarginTop`: number?
- `MarginBottom`: number?

## Specific methods
- `SetMargins()` — Set the top and bottom whitespace around the divider.
